Upload a new single

A 3-step helper that walks your brother through adding a track. No dev tools needed.

1 Upload the audio + cover art on GitHub

  1. Open the repo on GitHub in the browser.
  2. Go into the music-site/audio folder → click Add file → Upload files → drag your MP3 in → Commit.
  3. Go into the music-site/covers folder → same thing with the cover image (JPG or PNG, ideally square).

Tip: use short, lowercase filenames with no spaces — e.g. my-new-song.mp3 and my-new-song.jpg.

2 Fill in the details

3 Paste it into tracks.json

  1. In the repo, open music-site/tracks.json.
  2. Click the pencil icon (Edit).
  3. Paste the snippet from step 2 as a new entry inside the "tracks" array (add a comma after the last existing entry).
  4. Click Commit changes.
  5. Wait ~1 minute for GitHub Pages to rebuild — refresh the site and the new single will be on the page.

Example of the final tracks.json after adding a new song:

{ "tracks": [ { "id": "my-new-song", "title": "My New Single", "audio": "audio/my-new-song.mp3", "cover": "covers/my-new-song.jpg", "releaseDate": "2026-09-06" }, { "id": "older-song", "title": "Older Single", "audio": "audio/older.mp3", "cover": "covers/older.jpg", "releaseDate": "2026-08-01" } ] }
