Upload a new single

3 short steps. Works entirely in your Netlify dashboard — no coding.

1 Upload the MP3 + cover on Netlify

  1. Go to your Netlify site dashboard.
  2. Open Deploys → File browser (or drop an updated folder onto the drop area).
  3. Put the MP3 in audio/ and the cover image in covers/.

Tip: short, lowercase filenames with no spaces work best — my-song.mp3, my-song.jpg.

2 Fill in the details

3 Paste it into tracks.json

  1. Open tracks.json on Netlify's file browser (or edit it locally).
  2. Paste the snippet as a new entry inside the "tracks" array (add a comma after the last existing entry).
  3. Save / redeploy. The new single shows up on the site within ~15 seconds.

Example of a full tracks.json:

{ "tracks": [ { "id": "my-new-song", "title": "My New Single", "audio": "audio/my-song.mp3", "cover": "covers/my-song.jpg", "releaseDate": "2026-09-06" }, { "id": "older-song", "title": "Older Single", "audio": "audio/older.mp3", "cover": "covers/older.jpg", "releaseDate": "2026-08-01" } ] }
